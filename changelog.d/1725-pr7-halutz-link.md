- GDD 0.3 starting population (Refs #1725): on the inactive dark start's Historical ledger, each halutz map unit from the
  Hakhshara now lists the people record it stands for, and a veteran pioneer keeps that list. Return moves exactly that
  record to the nearest city as a settled-in civilian without a job, and Reassign takes the city's free pioneer records,
  lowest id first for the most service, back to the region. The pioneer's service is still kept on the city's counts, not
  on the person. A training order that takes a returned pioneer lowers the city's qualified pioneers by one, so a
  later reassignment still finds its people. A pioneer unit with no people record (one an event grants) makes one new
  settled-in pioneer when it returns, a beginner from a halutz unit and a veteran from a veteran unit. No new-game wiring, so there is no change in the game.
