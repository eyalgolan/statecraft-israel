# GDD v0.1 Phase 1: the vertical slice behind the switch. Implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (the controller chose inline execution, one PR at a time, no subagents). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build GDD v0.1 Phase 1 (one city, training, one pioneer action, one objective card, a minimal UI) behind a data switch, so that `hash1950`, `hash1952`, `smoke5`, `scenario-cautious` and `scenario-reckless` do not move.

**Architecture:** One `systems.loop` switch (`legacy` | `gdd`) in `eras.yaml` and a `turn_lengths` rules key. The real content keeps the defaults until the cutover PR (Phase 2). Tests, the new MVP goldens and a dev URL flag load the real content through `MvpSlice.Overlay`, which turns the switch on and sets monthly turns. New state is hashed only when it is not empty, so with the switch off `GameState.Describe()` is byte-identical to today. The GDD rules run in a new `TurnResolver`, called from `Simulation.Step` only when the loop is `gdd`.

**Tech stack:** C# netstandard2.1 sim (`sim/Statecraft.Sim`), xUnit tests on net10.0 (`sim/Statecraft.Sim.Tests`), YamlDotNet content, Unity 6000.3.25f1 UI Toolkit (`unity/`), Python tools and policy checks under `uv`.

**Spec:** [docs/superpowers/specs/2026-10-12-gdd-v0.1-impact-and-plan.md](../specs/2026-10-12-gdd-v0.1-impact-and-plan.md), §2, §3 and §6 "Phase 1". Design of record: [docs/GDD.md](../../GDD.md). Read both before a task.

```csharp
using System;
using System.Collections.Generic;
using System.IO;
using System.Linq;
using YamlDotNet.Serialization;

namespace Statecraft.Sim
{
    /// <summary>The GDD v0.1 slice before cutover (spec 2026-10-12 §2.1): the real content with the loop switch on and monthly
    /// turns. Tests, the MVP goldens and the dev flag load it; the real eras.yaml and rules.yaml keep the defaults until cutover.
    /// It edits YAML nodes, not text, so a comment or key order in the real files cannot break it.</summary>
    public static class MvpSlice
    {
        static readonly IDeserializer Reader = new DeserializerBuilder().Build();
        static readonly ISerializer Writer = new SerializerBuilder().Build();

        public static Func<string, string?> Overlay(Func<string, string?> readFile)
        {
            if (readFile == null) throw new ArgumentNullException(nameof(readFile));
            return rel =>
            {
                var text = readFile(rel);
                if (text == null) return null;
                if (rel == "eras.yaml")
                {
                    var root = Reader.Deserialize<Dictionary<object, object>>(text);
                    foreach (Dictionary<object, object> era in (List<object>)root["eras"])
                    {
                        var systems = era.TryGetValue("systems", out var x) && x is Dictionary<object, object> d ? d : new Dictionary<object, object>();
                        systems["loop"] = EraSystems.Gdd;
                        era["systems"] = systems;
                    }
                    return Writer.Serialize(root);
                }
                if (rel == "rules.yaml")
                {
                    var root = Reader.Deserialize<Dictionary<object, object>>(text);
                    root["turn_lengths"] = new List<object> { "month", "month", "month", "month", "month" };
                    return Writer.Serialize(root);
                }
                return text;
            };
        }

        /// <summary>The real content at <paramref name="contentRoot"/> through <see cref="Overlay"/>.</summary>
        public static Content Load(string contentRoot)
        {
            var eventsDir = Path.Combine(contentRoot, "events");
            var eventFiles = Directory.GetFiles(eventsDir, "*.yaml").Select(f => "events/" + Path.GetFileName(f)).ToList();
            return ContentLoader.Load(Overlay(rel => { var p = Path.Combine(contentRoot, rel); return File.Exists(p) ? File.ReadAllText(p) : null; }), eventFiles);
        }
    }
}
```

```csharp
        /// <summary>R-CITY-001: sets the number of the city's civilians in jobs (a standing order). Refused, state untouched, when the
        /// loop is legacy, the city or role is unknown, or the count is negative, above the job slots or above the civilians.</summary>
        public static string? Assign(Content c, GameState s, string city, string role, int count, List<Cause> why)
        {
            if (!c.IsGdd) return "That order is not available in this game";
            if (!s.Cities.TryGetValue(city, out var x)) return "There is no such city";
            if (role != "job") return "There is no such role";   // craftsman: Phase 3
            if (count < 0) return "The number of workers cannot be negative";
            if (count > x.JobSlots) return FormattableString.Invariant($"{PlayerText.Settlement(c, city)} has {x.JobSlots} jobs");
            if (count > x.Civilians) return FormattableString.Invariant($"{PlayerText.Settlement(c, city)} has {x.Civilians} civilians");
            s.Cities[city] = x.WithCounts(x.Civilians, count, x.Refugees);
            why.Add(new Cause("city", city, count - x.Employed, FormattableString.Invariant($"{PlayerText.Settlement(c, city)}: {count} groups in work")));
            return null;
```
