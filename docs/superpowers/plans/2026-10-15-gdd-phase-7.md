## Where things stand (read before a task)

On `main` (15 October 2026, `a8ae6d35`):
- **Events.** 31 event files in `content/events/`. `EventRules.SpecialTargets` is `treasury` and `fx_reserves`; every other target is an indicator (`EventRules.cs:12`). A sensitive option (tags `holocaust`, `terror`, `massacre`, `war-casualties`) cannot raise `treasury` or `fx_reserves` (`EventRules.cs:11`, the check in `Validate`). Hard anchors always fire; soft events fill the remaining slots of 3 a turn, ordered by `From`, then id (`EventSystem.Trigger`). An event left unanswered at End Turn is **delegated**: its office's holder picks the recommended option with probability competence/10, otherwise a random option; in Historical mode a hard anchor takes its historical option with no draw (`EventSystem.Delegate`).
- **The end.** `GameOverCodes` holds `era_ended` and `coalition_collapse` (`GameState.cs:11-16`). `Simulation.cs:79` sets `era_ended` with the comment "the legacy report (#19) will come before this once it exists". Unity has no end screen: the HUD only disables End Turn when `GameOver` is set (`HudPresenter.cs:173`).
- **Ministers.** `Cabinet.Appoint` with legality checks and a coalition-stability cost (`Cabinet.cs`). `EffectsSystem.Multiplier` is `(0.5 + competence / 20) × budget factor`, and an office with no holder counts as competence 0 (0.5) (`EffectsSystem.cs:19-25`). Policies in `model.yaml` name their office (`housing_construction`: `labour_minister`; `border_settlement`: `agriculture_minister`; `rationing`: `rationing_minister`).
- **Rule IDs** defined so far: R-TURN, R-LOOP, R-SAVE, R-CITY, R-TRAIN, R-ECON (`docs/rules/mvp.md`).

## Review focus

1. **A structured effect that breaks conservation or rewards harm.** A unit grant adds exactly the units it names and takes the next ids; a city effect changes only the field it names; no effect of a sensitive option adds units, Money, Arms, Food, cohesion, support or score (R-EFX-005). Tests: PR 2.
2. **An early armistice pushed off by the soft-event cap.** A `front_quiet` armistice is a soft event (Q-OBJ-1). With 3 soft slots a turn, it must never wait behind ordinary soft events. Test: PR 1 (`TheCapNeverDelaysAnArmistice`).
3. **A defeat that the historical run would hit.** The reference run and the Historical-mode run with no orders are never defeated before 15 January 1952. If a sourced enemy starting position shares a GDD city's hex (Jerusalem is the case to check), the war-loss rule must not fire on turn 1. Test: PR 5.
4. **A score that counts twice or misses a part.** The final score is exactly the sum of its parts on the end report (R-SCORE-001), and each objective scores once. Tests: PRs 6 and 7.
5. **The end report writes state.** It is a pure function of the final state and content; calling it twice gives the same text and changes no hash. Test: PR 7.
6. **Sensitive text without review.** Every new or changed card, the cutscene and the end screen's texts are listed in their PR for the owner's review, and the release gate refuses an unreviewed sensitive card (`ReleaseGate.cs`). Tests: PRs 3, 10, 13.
