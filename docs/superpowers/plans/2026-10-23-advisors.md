# Civ-style advisors Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Three advisors (David Ben-Gurion, Golda Meyerson, Moshe Dayan) teach each mechanic the first time the player meets it and warn as the game goes on, in a side popup, replacing the first-turn guide and How to play; the talking clips plug in last, once the owner picks how they are made.

**Architecture:** A Unity-side data file, `unity/Assets/Resources/Advisors/advisor-messages.yaml`, lists the advisors, their messages and the encyclopedia's pages; `AdvisorCatalog` loads and checks it. Small pure classes decide what shows: `AdvisorSignals` reads the state the screen shows, `AdvisorQueue` orders, caps and filters, `AdvisorLayout` places the popup, `AdvisorSettings` keeps the help level and the seen marks in the settings file. `AdvisorPresenter` draws the popup and hides it under every modal layer through one hook at the end of `ScreenNav.DisableCovered`. Media is one optional row per message: an optional picture file (a clip or a still; without one the advisor's portrait shows) under `StreamingAssets/advisors/`, a narration file per language and timed caption keys; `AdvisorMedia` plays whatever the row names, so the production route can change without touching code.

**Tech Stack:** C# in Unity 6000.3.25f1 (UI Toolkit, NUnit EditMode tests), YamlDotNet (already a Unity plugin), the netstandard2.1 sim (xUnit, `dotnet test sim/Statecraft.sln`) for one read-only helper, `scripts/check.sh`.

**Spec:** [docs/superpowers/specs/2026-10-23-advisors-design.md](../specs/2026-10-23-advisors-design.md) (merged as 945026bb, #1484). Read it first; section numbers below are the spec's. Every file:line below was read on origin/main `030263e4` (#1324 merged).

```csharp
#nullable enable
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text.RegularExpressions;
using UnityEngine;
using YamlDotNet.Serialization;
using YamlDotNet.Serialization.NamingConventions;

namespace Statecraft.Game.UI
{
    /// <summary>Reads and checks Assets/Resources/Advisors/advisor-messages.yaml (spec 4.1): the three advisors, their
    /// messages (a signal, a condition, a help level, a priority, a repeat rule, up to two actions) and the encyclopedia's
    /// pages. A Unity-side file, never part of the hashed game content.</summary>
    public sealed class AdvisorCatalog
    {
        public const string ResourcePath = "Advisors/advisor-messages";
        public const string Path = "Assets/Resources/Advisors/advisor-messages.yaml";
        public static readonly string[] AdvisorIds = { "ben_gurion", "meyerson", "dayan" };
        /// <summary>The lowest help level that shows a message, from the chattiest (spec 6); "critical" shows at every level.</summary>
        public static readonly string[] Levels = { "new", "experienced", "warnings", "critical" };
        public const string Once = "once", Every = "every", Approved = "approved", Pending = "pending";
        public const int MaxWords = 35;
        static readonly Regex IdPattern = new Regex("^[a-z0-9_.]+$", RegexOptions.CultureInvariant);

        public sealed class Advisor { public string Id { get; set; } = ""; public string Person { get; set; } = ""; }

        /// <summary>One button: Show me's named target, a side screen, an encyclopedia page, or the decision card.</summary>
        public sealed class Act
        {
            public string ShowMe { get; set; } = "";
            public string OpenScreen { get; set; } = "";
            public string Encyclopedia { get; set; } = "";
            public bool OpenCard { get; set; }
        }

        public sealed class Message
        {
            public string Id { get; set; } = "";
            public string Advisor { get; set; } = "";
            public string Signal { get; set; } = "";
            public Dictionary<string, double> When { get; set; } = new Dictionary<string, double>();
            public List<string> Requires { get; set; } = new List<string>();
            public string Level { get; set; } = "";
            public int Priority { get; set; } = 1;
            public string Repeat { get; set; } = Once;

        {

            foreach (var id in AdvisorIds)
                if (Advisors.Count(a => a.Id == id) != 1) p.Add($"advisors: '{id}' must be listed once");
            foreach (var a in Advisors)
            {
                if (!AdvisorIds.Contains(a.Id)) p.Add($"advisors: unknown advisor '{a.Id}'");
                if (a.Person.Trim() == "") p.Add($"advisors: '{a.Id}' names no person");
            }
            foreach (var g in Messages.GroupBy(m => m.Id).Where(g => g.Count() > 1)) p.Add($"{g.Key}: listed more than once");
            foreach (var m in Messages)
            {
                var at = m.Id;
                if (!IdPattern.IsMatch(m.Id)) p.Add($"{at}: an id is lower-case letters, digits, '_' and '.'");
                if (!AdvisorIds.Contains(m.Advisor)) p.Add($"{at}: unknown advisor '{m.Advisor}'");
                if (!known.Signals.Contains(m.Signal)) p.Add($"{at}: unknown signal '{m.Signal}'");
                foreach (var k in m.When.Keys) if (!known.Conditions.Contains(k)) p.Add($"{at}: unknown condition '{k}'");
                foreach (var r in m.Requires) if (!byId.ContainsKey(r)) p.Add($"{at}: requires unknown message '{r}'");
                if (!Levels.Contains(m.Level)) p.Add($"{at}: level must be one of {string.Join(", ", Levels)}");
                if (m.Priority < 1 || m.Priority > 3) p.Add($"{at}: priority must be 1 to 3");
                if (m.Repeat == Once && m.CooldownTurns != 0) p.Add($"{at}: once has no cooldown_turns");
                else if (m.Repeat == Every && m.CooldownTurns < 1) p.Add($"{at}: every needs cooldown_turns of at least 1");
                else if (m.Repeat != Once && m.Repeat != Every) p.Add($"{at}: repeat must be once or every");
                if (m.Actions.Count > 2) p.Add($"{at}: at most two actions");
                foreach (var a in m.Actions) CheckAct(p, at, a, known);
                if (m.Quote != "" && !known.Quotes.Contains(m.Quote)) p.Add($"{at}: quote '{m.Quote}' is not on the verified list (spec 3.3)");
                if (m.DisagreesWith != "")
                {
                    var o = Find(m.DisagreesWith);
                    if (o == null || o.Advisor == m.Advisor || o.DisagreesWith != m.Id)
                        p.Add($"{at}: disagrees_with must name another advisor's message that names this one back");
                }
                if (m.HeReview != Pending && m.HeReview != Approved) p.Add($"{at}: he_review must be pending or approved");
                Text(p, en, he, at, "advisor." + m.Id + ".text", MaxWords);
            }
            if (Cycle() is string c) p.Add("requires has a cycle: " + c);
            foreach (var g in Pages.GroupBy(x => x.Id).Where(g => g.Count() > 1)) p.Add($"page {g.Key}: listed more than once");
            foreach (var page in Pages)
            {
                var at = "page " + page.Id;
                if (!IdPattern.IsMatch(page.Id)) p.Add($"{at}: an id is lower-case letters, digits, '_' and '.'");
                if (!AdvisorIds.Contains(page.Advisor)) p.Add($"{at}: unknown advisor '{page.Advisor}'");
                if (page.ShowMe != "" && !known.Targets.Contains(page.ShowMe)) p.Add($"{at}: unknown show_me target '{page.ShowMe}'");
                if (page.HeReview != Pending && page.HeReview != Approved) p.Add($"{at}: he_review must be pending or approved");
                Text(p, en, he, at, "advisor.page." + page.Id + ".title", 0);
                Text(p, en, he, at, "advisor.page." + page.Id + ".text", 0);
            }
            return p;
        }

        void CheckAct(List<string> p, string at, Act a, Known known)
        {
            int set = (a.ShowMe != "" ? 1 : 0) + (a.OpenScreen != "" ? 1 : 0) + (a.Encyclopedia != "" ? 1 : 0) + (a.OpenCard ? 1 : 0);
            if (set != 1) p.Add($"{at}: each action names exactly one of show_me, open_screen, encyclopedia, open_card");
            if (a.ShowMe != "" && !known.Targets.Contains(a.ShowMe)) p.Add($"{at}: unknown show_me target '{a.ShowMe}'");
            if (a.OpenScreen != "" && !known.Screens.Contains(a.OpenScreen)) p.Add($"{at}: unknown screen '{a.OpenScreen}'");
            if (a.Encyclopedia != "" && !pageById.ContainsKey(a.Encyclopedia)) p.Add($"{at}: unknown page '{a.Encyclopedia}'");
        }

        static void Text(List<string> p, UiText en, UiText he, string at, string key, int maxWords)
        {
            foreach (var (t, lang) in new[] { (en, "en"), (he, "he") })
            {
                if (!t.Has(key) || string.IsNullOrWhiteSpace(t[key])) { p.Add($"{at}: no {key} in strings.{lang}.yaml"); continue; }
                if (t[key].IndexOf('\u2014') >= 0) p.Add($"{at}: {key} in strings.{lang}.yaml has an em dash");
            }
            if (maxWords > 0 && en.Has(key) && en[key].Split(new[] { ' ' }, StringSplitOptions.RemoveEmptyEntries).Length > maxWords)
                p.Add($"{at}: {key} is over {maxWords} words");
        }

        /// <summary>The first requires cycle found, as "a -> b -> a", or null.</summary>
        string? Cycle()
        {
            var state = new Dictionary<string, int>(StringComparer.Ordinal);   // 1 visiting, 2 done
            var path = new List<string>();
            string? Visit(string id)
            {
                if (state.TryGetValue(id, out var s)) return s == 1 ? string.Join(" -> ", path.SkipWhile(x => x != id).Append(id)) : null;
                state[id] = 1; path.Add(id);
                foreach (var r in Find(id)?.Requires ?? new List<string>()) if (byId.ContainsKey(r) && Visit(r) is string c) return c;
                path.RemoveAt(path.Count - 1); state[id] = 2;
                return null;
            }
            foreach (var m in Messages) if (Visit(m.Id) is string c) return c;
            return null;
        }
    }
```

```csharp
#nullable enable
using System;
using System.Collections.Generic;
using System.Linq;
using UnityEngine;

namespace Statecraft.Game.UI
{
    /// <summary>The advisors' lines in the settings file (spec 15; SettingsStore: presentation only, never the sim or the
    /// save): the help level, the messages seen (one line, advisor_seen=a,b,c) and the opening chain's mark. The marks
    /// are also kept in memory, so a failed write (logged) or no file at all (automated runs) only costs persistence.</summary>
    public sealed class AdvisorSettings
    {
        public const string LevelKey = "advisor_level", SeenKey = "advisor_seen", OpeningKey = "advisor_opening";
        /// <summary>The first-turn guide's line (spec 9.3: honoured, so a player who saw the guide gets no chain by itself).</summary>
        public const string GuideSeenKey = "first_turn_guide";
        /// <summary>Spec 6, from the chattiest; a message shows when its level's index (AdvisorCatalog.Levels) is at least this one's.</summary>
        public static readonly string[] Levels = { "new", "experienced", "warnings", "off" };

        readonly SettingsStore? store;
        readonly SortedSet<string> seen = new SortedSet<string>(StringComparer.Ordinal);
        bool openingSeen;

        public AdvisorSettings(SettingsStore? store)
        {
            this.store = store;
            var stored = store?.Read(LevelKey);
            Level = Array.IndexOf(Levels, stored) >= 0 ? stored! : Levels[0];
            foreach (var id in (store?.Read(SeenKey) ?? "").Split(new[] { ',' }, StringSplitOptions.RemoveEmptyEntries)) seen.Add(id);
            openingSeen = store?.Read(OpeningKey) == "seen" || store?.Read(GuideSeenKey) == "seen";
        }

        /// <summary>A settings file exists to remember the marks in (none in automated runs and EditMode tests).</summary>
        public bool HasFile => store != null;
        public string Level { get; private set; }
        public int LevelRank => Array.IndexOf(Levels, Level);

        public void SetLevel(string level)
        {
            if (Array.IndexOf(Levels, level) < 0) throw new ArgumentException("unknown help level: " + level, nameof(level));
            Level = level;
            Write(LevelKey, level);
        }

        public bool Seen(string id) => seen.Contains(id);

        public void MarkSeen(string id)
        {
            if (!seen.Add(id)) return;
            Write(SeenKey, string.Join(",", seen));
        }

        public bool OpeningSeen => openingSeen;

        public void MarkOpeningSeen()
        {
            openingSeen = true;
            Write(OpeningKey, "seen");
        }

        void Write(string key, string value)
        {
            if (store == null) return;
            try { store.Write(key, value); }
            catch (Exception e) { Debug.LogWarning($"The advisors could not save {key}: {e.Message}"); }
        }
    }
}
```

```csharp
#nullable enable
using System;
using System.Collections.Generic;
using System.Linq;

namespace Statecraft.Game.UI
{
    /// <summary>The messages waiting to show (spec 4.2): critical first, then the higher priority, then the order the signals
    /// fired. At most one teaching message and one non-critical warning show by themselves a turn; the rest wait for the
    /// next turn or Counsel. A critical message is never held back (spec 6: the advisors never stay silent on a real
    /// threat). Filters by the help level and, in Hebrew, by approval (OQ-4) when it is asked, so a Settings change or a
    /// language switch applies at once. Keeps this game's history for Counsel (spec 7.4); none of it is saved.</summary>
    public sealed class AdvisorQueue
    {
        public enum Outcome { Shown, PutOff, Missed }

        public readonly struct Entry
        {
            public Entry(string id, int turn, DateTime date, Outcome outcome) { Id = id; Turn = turn; Date = date; Outcome = outcome; }
            public string Id { get; }
            public int Turn { get; }
            public DateTime Date { get; }
            public Outcome Outcome { get; }
        }

        sealed class Waiting { public AdvisorCatalog.Message M = null!; public int Seq; public int NotBefore; public bool PutOff; }

        readonly AdvisorCatalog catalog; readonly AdvisorSettings settings;
        readonly List<Waiting> waiting = new List<Waiting>();
        readonly List<Entry> history = new List<Entry>();
        readonly Dictionary<string, int> lastShown = new Dictionary<string, int>(StringComparer.Ordinal);
        int seq, capTurn = int.MinValue, shownThisTurn;
        bool teachingShown, warningShown;

        public AdvisorQueue(AdvisorCatalog catalog, AdvisorSettings settings) { this.catalog = catalog; this.settings = settings; }

        public IReadOnlyList<Entry> History => history;
        public IEnumerable<string> PutOffIds => waiting.Where(w => w.PutOff).Select(w => w.M.Id);

        /// <summary>Queues each message whose signal holds now and whose condition holds, unless it is already waiting, is
        /// filtered out (Eligible) or waits on a message not yet seen.</summary>
        public void Offer(IReadOnlyCollection<string> holding, Func<IReadOnlyDictionary<string, double>, bool> when, int turn)
        {
            foreach (var m in catalog.Messages)
            {
                if (!holding.Contains(m.Signal) || waiting.Any(w => w.M == m)) continue;
                if (!Eligible(m, turn) || !when(m.When)) continue;
                waiting.Add(new Waiting { M = m, Seq = seq++, NotBefore = turn });
            }
        }

        bool Eligible(AdvisorCatalog.Message m, int turn) =>
            Array.IndexOf(AdvisorCatalog.Levels, m.Level) >= settings.LevelRank
            && (m.Repeat == AdvisorCatalog.Once ? !settings.Seen(m.Id) : !(lastShown.TryGetValue(m.Id, out var t) && turn < t + m.CooldownTurns))
            && m.Requires.All(settings.Seen);

        void Caps(int turn)
        {
            if (turn == capTurn) return;
            capTurn = turn; teachingShown = warningShown = false; shownThisTurn = 0;
        }

        bool UnderCap(AdvisorCatalog.Message m) => m.Critical || !(m.Teaching ? teachingShown : warningShown);

        IEnumerable<AdvisorCatalog.Message> Showable(int turn, bool hebrew)
        {
            Caps(turn);
            return waiting.Where(w => w.NotBefore <= turn && Eligible(w.M, turn) && w.M.ApprovedIn(hebrew) && UnderCap(w.M))
                .OrderByDescending(w => w.M.Critical).ThenByDescending(w => w.M.Priority).ThenBy(w => w.Seq).Select(w => w.M);
        }

        public AdvisorCatalog.Message? Head(int turn, bool hebrew) => Showable(turn, hebrew).FirstOrDefault();

        /// <summary>The counter (spec 7.1, "1 of 3"): this one's place among those shown this turn and those still showable.</summary>
        public (int number, int total) Position(int turn, bool hebrew)
        {
            var left = Showable(turn, hebrew).ToList();
            // At most one more teaching and one more warning can follow by themselves, however many wait.
            int more = left.Count(m => m.Critical) + (left.Any(m => !m.Critical && m.Teaching) ? 1 : 0) + (left.Any(m => !m.Critical && !m.Teaching) ? 1 : 0);
            return (shownThisTurn + 1, shownThisTurn + more);
        }

        /// <summary>Got it or the X: seen (once), or its cooldown starts (every); it uses its kind's slot; into the history.</summary>
        public void Done(AdvisorCatalog.Message m, int turn, DateTime date)
        {
            Take(m, turn);
            if (m.Repeat == AdvisorCatalog.Once) settings.MarkSeen(m.Id); else lastShown[m.Id] = turn;
            history.Add(new Entry(m.Id, turn, date, Outcome.Shown));
        }

        /// <summary>Not now: off to the next turn, and into the history as put off. A critical message has no Not now.</summary>
        public void PutOff(AdvisorCatalog.Message m, int turn, DateTime date)
        {
            if (m.Critical) throw new InvalidOperationException($"{m.Id} is critical: it has no Not now");
            Take(m, turn);
            waiting.Add(new Waiting { M = m, Seq = seq++, NotBefore = turn + 1, PutOff = true });
            history.Add(new Entry(m.Id, turn, date, Outcome.PutOff));
        }

        /// <summary>A layer covered it and its signal no longer holds when the layer closed (spec 4.2): into the history,
        /// not shown again now, and not marked seen, so its signal can bring it back later.</summary>
        public void Drop(AdvisorCatalog.Message m, int turn, DateTime date)
        {
            waiting.RemoveAll(w => w.M == m);
            history.Add(new Entry(m.Id, turn, date, Outcome.Missed));
        }

        void Take(AdvisorCatalog.Message m, int turn)
        {
            Caps(turn);
            waiting.RemoveAll(w => w.M == m);
            shownThisTurn++;
            if (m.Critical) return;
            if (m.Teaching) teachingShown = true; else warningShown = true;
        }

        /// <summary>A new or loaded game: nothing waits and the history starts empty (the seen marks stay: they are the player's).</summary>
        public void Reset()
        {
            waiting.Clear(); history.Clear(); lastShown.Clear();
            capTurn = int.MinValue; shownThisTurn = 0; teachingShown = warningShown = false;
        }
    }
}
```

```csharp
#nullable enable
using UnityEngine;
using UnityEngine.UIElements;

namespace Statecraft.Game.UI
{
    public enum HudTier { OneRow, TwoRow, ThreeRow }

    /// <summary>Where the advisor popup goes (spec 7.1), in panel px. One and two rows: the right column's upper part,
    /// 400 px wide, its top under the "Decision waiting" row whether or not it shows (so it never jumps), its foot 12 px
    /// above the minimap. An upright phone (three rows): a sheet from the left column's edge to the window's right edge,
    /// under "Decision waiting" and the toast, its foot 12 px above the higher of the info panel and the minimap's label.
    /// Hebrew: the same place (the HUD does not mirror its panels, Statecraft.uss:943-946).</summary>
    public static class AdvisorLayout
    {
        public const float Width = 400f, EdgePx = 16f, GapPx = 12f, DecisionRowPx = 46f, BelowPx = 8f;

        public static HudTier Tier(VisualElement hudRoot) =>
            hudRoot.ClassListContains(HudPresenter.ThreeRowClass) ? HudTier.ThreeRow
            : hudRoot.ClassListContains(HudPresenter.TwoRowClass) ? HudTier.TwoRow : HudTier.OneRow;

        public static Rect Slot(HudTier tier, Rect window, Rect rightColumn, Rect leftColumn, Rect minimap,
            Rect? decisionWaiting, Rect? toast, Rect? infoPanel, Rect? mapLabel)
        {
            float right = window.xMax - EdgePx;
            if (tier != HudTier.ThreeRow)
                return Rect.MinMaxRect(right - Width, rightColumn.yMin + DecisionRowPx + BelowPx, right, minimap.yMin - GapPx);
            float top = rightColumn.yMin;
            if (decisionWaiting is Rect d) top = Mathf.Max(top, d.yMax + BelowPx);
            if (toast is Rect t) top = Mathf.Max(top, t.yMax + BelowPx);
            float floor = minimap.yMin;
            if (mapLabel is Rect m) floor = Mathf.Min(floor, m.yMin);
            if (infoPanel is Rect i) floor = Mathf.Min(floor, i.yMin);
            return Rect.MinMaxRect(leftColumn.xMax + GapPx, top, right, floor - GapPx);
        }

        /// <summary>The popup's rectangle in its slot: at the top, or at the foot when that keeps it off
        /// <paramref name="avoid"/> (Show me's target, spec 7.3); never taller than the slot.</summary>
        public static Rect Place(Rect slot, float height, Rect? avoid)
        {
            float h = Mathf.Min(height, slot.height);
            var top = new Rect(slot.xMin, slot.yMin, slot.width, h);
            if (!(avoid is Rect a) || !top.Overlaps(a)) return top;
            var foot = new Rect(slot.xMin, slot.yMax - h, slot.width, h);
            return foot.Overlaps(a) ? top : foot;
        }
    }
}
```

```csharp
        {
```

```csharp
                else if (a.OpenCard && hooks.Card?.Shown != null) hooks.Card.Reopen();

        {

            Render();
        }

        }

        }
    }
```

```csharp
using System;
using System.Collections.Generic;
using System.Globalization;
using System.Linq;

namespace Statecraft.Sim
{
    /// <summary>The advisors' one sim helper (docs/superpowers/specs/2026-10-23-advisors-design.md, section 5): the player's
    /// cities the enemy is likely to attack or enter this turn. It runs resolver step 1 (EnemyAI.Order, R-ENEMY-001) on a
    /// copy of the state and reads the copy: an attack order on a city's hex, or an enemy unit standing on one. It changes
    /// nothing and draws no random number. "Likely": the player's own orders this turn can still change the board.</summary>
    public static class Threats
    {
        public static IReadOnlyList<string> CitiesAtRisk(Content c, GameState s)
        {
            if (!c.IsGdd || s.GameOver != null) return Array.Empty<string>();
            var copy = s.Clone();
            EnemyAI.Order(c, copy, new List<Cause>(), Simulation.TurnEnd(c, s));
            var cityAt = new Dictionary<string, string>(StringComparer.Ordinal);
            foreach (var h in c.SettlementHexes) if (s.Cities.ContainsKey(h.Id)) cityAt[Hex(h.Q, h.R)] = h.Id;
            var risk = new SortedSet<string>(StringComparer.Ordinal);
            foreach (var u in copy.Units.Values)
            {
                if (u.Side == "" || u.Side == Movement.PlayerSide) continue;
                if (u.Order == Combat.Attack && cityAt.TryGetValue(u.OrderTarget, out var attacked)) risk.Add(attacked);
                if (cityAt.TryGetValue(Hex(u.Q, u.R), out var entered)) risk.Add(entered);
            }
            return risk.ToList();
        }

        static string Hex(int q, int r) => string.Format(CultureInfo.InvariantCulture, "{0},{1}", q, r);
    }
}
```
