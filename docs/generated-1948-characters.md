# Generated 1948 characters

Seven characters generated by Tal Heuberger on 22 October 2026, credited under CC BY-NC-ND 4.0. Exact provider GLBs and their embedded 4096px JPEG payloads are retained in `asset-sources/generated-1948/`. The provider supplied GLB, not FBX. The Unity FBX files are explicitly documented compatibility conversions preserving full source geometry and skin weights. Provider rigged GLBs contain zero animation clips. Both existing local idle/walk retargets are retained at every frame without key reduction. The six token figures (the Syrian, Iraqi, Egyptian and ALA infantry, the Lebanese regular and the local Arab irregular) also get a walk state, and an attack state where their model has a fire take, in their controllers (`CollectionImport.AddMotionStates`); a moving token plays the walk (`UnitTokenMotion`). The Bedouin civilian keeps idle only. Exact authoring F-curves, keys and handles are archived as byte-verified gzip JSON (archival data only); FBX interpolation conversion has measured numerical differences, recorded per character.

## Import and review

`Generated1948Characters.Run` explicitly imports the seven named characters with mesh and animation compression Off, no Crunch, original-size maps and all available clips. Runtime prefabs play idle at rest and, for the six token figures, walk when their token moves (see above). `CollectionImport` delegates the seven runtime generated characters to this full-quality importer and preserves older import settings. Original C09 model files and metadata remain unchanged.

Open `Assets/Editor/Generated1948CharacterReview.unity`, or use Statecraft → Character review → Play seven generated characters. The stage is isolated, not a historical map or player capture. Camera angle, idle/walk, orientation and floor-contact checks remain available.
