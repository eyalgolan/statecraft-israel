This presentation configuration is independent of the simulation ruleset. Source: **owner ruling, 26 Oct 2026, #1273: Yes, build it**. No private bootstrap, external experiment YAML, experiment define or global policy install/uninstall ships. Diagnostic scans/JSON are off by default and opt-in only in editor/development builds. With diagnostics off, the destruction and lease-release wait remains active; receipts are recorded only with diagnostics on. No diagnostic route or unit wait is added to normal gameplay or capture flow.
