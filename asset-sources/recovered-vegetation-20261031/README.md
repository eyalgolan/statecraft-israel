# Recovered papyrus and tamarisk sources

Refs #1951, #1939, #1950 and #1952. Six original prepared source files are recovered here: g25_papyrus (2,260 triangles), hf_tamarisk (7,306 triangles), and each model’s albedo and normal JPG. These exact variants match archived marsh prefab mesh references. The files were copied byte for byte; no regeneration or further simplification occurred.

This is source recovery, not current hula_swamp registration or completed regional reuse. No Unity prefabs, GUID metadata, materials, provider masters, alternative variants, concept images or archival photographs are added. An importer must bind the paired albedo/normal maps and agree destination identifiers, scale and placement through the existing hex workflow. Archived hula_marsh references do not establish current registration. Shared tamarisk/reeds/well decisions on #1951 remain.
